# Continue this project on another device

## Requirements

- Node.js 22.13 or newer; Node.js 24 LTS is recommended
- npm, which is included with Node.js

## Start the site

1. Extract the ZIP.
2. Open a terminal inside the extracted `disney-multi-realm-homepage` folder.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost address printed in the terminal.

## Main files to edit

- `app/page.tsx` contains the homepage content, sections and interaction logic.
- `app/globals.css` contains the full visual design, responsive layouts and animation system.
- `public/assets` contains all current image files.
- `ASSET-GUIDE.md` lists source links and recommended specifications for replacement images and videos.

## Useful checks

- `npm run lint` checks the application source.
- `npm run build` creates a production build.

The ZIP intentionally excludes `node_modules`, `dist` and Git history. Those are generated or machine-specific and are not needed to continue editing.
